# 知识卡片制作

## 概述

把一篇完整文章压缩成若干张"一张一个知识点"的卡片，目标是让人只看卡片就能回忆出原文的骨架与要点。卡片是知识的索引与复习单位，不是原文缩写——宁可少而准，不可多而空。

## 适用范围

支持：
- 用户在对话里粘贴的文章正文
- 本地 `.md` / `.txt` 文件（单个或多个）
- 中文或外文原文（输出语言跟随原文）

不支持，遇到时直接说明并给出替代做法：
- 网页抓取（请用户粘贴正文）
- PDF / 图片 / 扫描件（请用户先转成文本）
- Anki、CSV、JSON 等导出格式
- 图形界面、可视化排版

## 工作流程

### 第 1 步：取文

- 粘贴文本：直接作为原文使用。
- 文件路径：用读取文件工具读出内容；多个文件逐个处理，并在每份结果开头标注文件名。
- 输入为空、路径不存在、或内容明显是目录/占位符：停下来说明问题，请用户补正文。不要凭空续写。

### 第 2 步：建立知识点候选池

通读全文，逐段标出"可以独立成一张卡片"的最小知识单元。一个知识单元指下列之一：

- 一个概念或定义
- 一条因果关系或机制
- 一个可执行的方法 / 步骤单元
- 一组对比或分类
- 一条有数据或案例支撑的结论
- 一条边界条件、例外或常见误区

### 第 3 步：筛选（决定留什么）

保留，按优先级从高到低：

1. 能迁移到其他场景的原理与机制
2. 与主题直接相关的因果链
3. 可照着做的方法与步骤
4. 反直觉的结论，或带边界条件的结论
5. 原文反复强调、或给出数据/案例支撑的观点

丢弃：

- 铺垫、背景介绍、修辞与过渡句
- 作者个人经历细节、情绪表达、自我推荐
- 广告、引流、课程推销、免责声明
- 没有信息增量的重复表述

### 第 4 步：去重与合并

- 同一知识点在不同段落重复出现：合并为一张，解释里可注明"原文在 X、Y 两处强调"。
- 上下位关系：下位点各自独立重要时分开成卡，否则并入上位概念。
- 同一概念的并列子项超过 4 条（如"某物分甲乙丙丁戊五类"）：合并成一张"分类卡"，不要每类一张。
- 注意区分两种"并列"：并列子项是同一个知识点的分支，该合并；而清单型文章里的每条建议各自是一个独立知识点（能单独拿走使用），该分开。判断标准是"抽掉其中一条，其余是否仍然成立"——仍然成立则分开，不成立则合并。
- 被迫合并（超过 8 张时）优先合并"同一场景、同一渠道"的相邻条目；合并后的核心知识允许是同一个动作的两个限定条件（如"能写就不说，写时先给结论"），但不允许把两个无关知识点缝在一起。

### 第 5 步：排序

按认知顺序排，不要按原文出现顺序机械排列。默认采用：是什么 → 为什么 → 怎么做 → 注意什么。原文本身有清晰骨架时，跟随原文骨架。

### 第 6 步：写卡片

固定结构，逐字段照写：

```markdown
### 卡片 N：{标题}

**核心知识**：{一句话，陈述句，可直接背下来}

**简明解释**：{1-4 句，讲清来由、条件或机制}

**{例子｜自测问题}**：{内容}
```

字段规则：

- 标题：≤ 14 字，具体到脱离上下文也能看懂；不要用"第一部分""核心观点"这类空标题。
- 核心知识：≤ 40 字，一句陈述句；不出现"并且""另外""同时"等并列词——出现即说明这张卡塞了两个知识点，需拆分。
- 简明解释：用自己的话重组，禁止整段照抄原文；只解释不自证，不重复核心知识的字面。
- 原文某个知识点本身只有一句话、没有可展开的机制或论证时，解释写 1-2 句即可（说明适用条件或该怎么用）。不要为了凑够句子数而补充原文没有的论证——卡片短不是缺陷，注水才是。
- 例子或自测问题（二选一，按内容决定）：
  - 原文本身有例子：优先用原文的例子，可压缩但不得改动事实，并在末尾标注"（原文例子）"。
  - 原文没有例子：改写自测问题，默认形式如"如果出现 X 情况，按原文应该怎么处理？为什么？"
  - 概念、原理类更适合例子；方法、流程类更适合自测问题。
  - 自测问题必须以原文能回答为限。不要问原文没有交代的问题（例如原文只给了结论没给原因，就不要问"为什么会这样"），否则等于诱导自己编答案。原文确实没展开时，在解释末尾注明"原文未展开"。
- 核心知识、解释、问题三处不要重复同一个数字或同一句判断，卡片内部要递进而不是复读。

### 第 7 步：数量控制

- 目标 5-8 张。
- 候选知识点不足 5 个：输出实际数量（可以是 2-4 张），并在结果开头加一行说明，例如"原文有效知识点 3 个，未凑数"。绝不靠拆句、重复、加废话凑到 5 张。
- 候选知识点超过 8 个：合并次要项后封顶 8 张。
- 极短输入（不足 200 字且只有一个要点）：输出 1-2 张，并说明输入信息量有限。
- 凡是做过合并或舍弃，都在结尾补一行说明合并了哪些、舍弃了什么理由，让用户能复查取舍是否合理。

## 反编造红线

以下五条，任何一条被破坏都算任务失败：

1. 不引入原文没有的事实、数字、人名、时间、机构、结论。
2. 不把推断写成原文结论。核心知识与解释中出现的每个判断，都应能在原文找到对应句。
3. 解释只做原文信息的重述与串联，不新增因果。原文只给结论时，解释里就只写条件和用法，不要替它编一个"因为"。
4. 不自行编造例子。需要举例而原文没有，改写成自测问题。
5. 必须补充背景才能讲通时，最多一处，单独用引用块标注 `> 补充（原文未提及）：……`，且不得含具体数字或专有事实。

原文表述含糊时，沿用原文措辞，不要替作者补全逻辑。

## 输出格式

```markdown
{一行元信息：来源（粘贴文本 / 文件名）+ 卡片数 +（如有）知识点不足说明}

### 卡片 1：……

### 卡片 2：……

……

{结尾一行（可选）：合并/舍弃说明}
```

- 元信息一行写完，不写导语、不写"以下是……"、不复述任务。
- 卡片之间空一行，不加额外的总述段落。
- 不要输出原文链接、原文摘要、思维导图等多余额外内容。

## 输入类型适配

| 文章类型 | 处理要点 |
| --- | --- |
| 科普 / 原理型长文 | 一张卡一个机制；优先保留因果链与边界条件；数据只保留支撑结论的那一个 |
| 教程 / 操作型 | 一张卡对应一个可独立执行的操作单元；步骤细节写进解释，不把整条流程压成一张 |
| 清单 / 列表型（如"10 个技巧"） | 每条技巧独立成立则各成一张，总数封顶 8；超出部分按重要性合并或舍弃并说明 |
| 观点 / 评论型 | 拆成"主张 + 论据"，明确区分作者主张与客观事实，不替作者站队 |
| 访谈 / 对话记录 | 只抽可复用的观点与方法，剔除寒暄、个人故事细节、口癖 |
| 代码 / 公式密集 | 必要的片段保留在解释里且不超过 5 行；不整段粘贴代码 |
| 超长文（约 1 万字以上） | 先按小标题分块筛选，再跨块去重；不要逐段成卡 |

## 交付前自检

逐条核对，任一不通过就返工后再输出：

1. 每张卡能否用一句话概括，且不出现并列连接词？
2. 是否有两张卡讲同一件事？
3. 核心知识与解释中的每个事实，能否在原文找到出处？
4. 标题是否具体（不看解释也能知道讲什么）？
5. 数量在 5-8 之间，或已说明不足 / 合并原因？
6. 是否已剔除作者经历、情绪、广告、铺垫？
7. 例子是否来自原文，或已改成自测问题？
8. 是否存在任何原文没有的数字、结论、案例？
9. 每个自测问题，是否都能用原文内容回答？
10. 做过合并或舍弃时，结尾是否说明了取舍？

## 完整示例

输入（原文节选）：

> 睡眠分为浅睡、深睡和快速眼动（REM）三个阶段，一个周期约 90 分钟。深睡主要发生在前半夜，负责身体修复和免疫调节；REM 多在后半夜，与记忆巩固相关。因此熬夜到凌晨再补觉，损失的深睡较少，但 REM 明显不足。咖啡因的半衰期约 5 小时，下午三点后摄入，到晚上十点体内仍残留约四分之一，会推迟入睡时间。

输出：

> 来源：粘贴文本｜卡片 4 张

### 卡片 1：睡眠周期约 90 分钟

**核心知识**：一个睡眠周期约 90 分钟，由浅睡、深睡、REM 三个阶段组成。

**简明解释**：整夜睡眠是多个周期循环，而不是一次从浅到深的单向过程。理解周期结构，才能理解后文"前半夜与后半夜睡的不是同一种觉"。

**自测问题**：如果只睡一个 90 分钟的周期就起床，身体会缺少哪些阶段？

### 卡片 2：深睡在前半夜，REM 在后半夜

**核心知识**：深睡集中在前半夜负责修复，REM 集中在后半夜负责记忆。

**简明解释**：两个阶段在夜间的分布不对称，因此"少睡前半段"和"少睡后半段"的代价不同。这也是判断"补觉能不能补回来"的依据。

**自测问题**：凌晨两点睡到中午十二点，睡眠时长够了，哪个阶段仍然会不足？

### 卡片 3：熬夜补觉补不回 REM

**核心知识**：熬夜到凌晨再补觉，损失的深睡较少，但 REM 明显不足。

**简明解释**：这是卡片 2 的直接推论——后半夜被压缩掉的正是 REM 密集区。补觉能延长总时长，但无法把错过的 REM 挪回原位。

**自测问题**：为什么"睡够 8 小时"不等于"睡得好"？

### 卡片 4：咖啡因半衰期约 5 小时

**核心知识**：咖啡因半衰期约 5 小时，下午三点后摄入会影响入睡。

**简明解释**：按 5 小时衰减，下午三点喝的咖啡到晚上十点仍残留约四分之一剂量，足以推迟入睡时间。判断标准是"离入睡还剩几个半衰期"，不是"有没有困意"。

**自测问题**：计划晚上十一点睡，最后一杯咖啡最晚应该在几点前喝完？

（四段原文各出一个独立机制，自然成 4 张；未凑到 5 张。）
